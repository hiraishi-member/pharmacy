# お薬管理アプリ — 要件定義書

## 1. アプリ概要・目的

毎日の服薬管理を簡単に行えるスマホ向けWebアプリ。

- お薬の登録・編集・削除
- 日次の服薬チェック（飲んだ／飲んでない）
- カレンダーで服薬履歴を振り返り

**ゴール**: 飲み忘れを減らし、服薬状況をひと目で把握できるようにする。

---

## 2. ユーザーストーリー

| # | ストーリー |
|---|-----------|
| US-1 | ユーザーとして、お薬を名前・服用タイミングと共に登録したい |
| US-2 | ユーザーとして、登録済みのお薬情報を編集・削除したい |
| US-3 | ユーザーとして、今日飲むべきお薬の一覧を確認し、飲んだらチェックしたい |
| US-4 | ユーザーとして、カレンダーで過去の服薬履歴を確認したい |
| US-5 | ユーザーとして、スマホで快適に操作したい |

---

## 3. 機能要件

### 3.1 お薬登録・管理

- お薬の新規登録（名前、服用タイミング、メモ）
- 登録済みお薬の一覧表示
- お薬情報の編集
- お薬の削除（確認ダイアログ付き）

### 3.2 服用タイミング

4区分で管理する:

| 区分 | ラベル |
|------|--------|
| morning | 朝 |
| noon | 昼 |
| evening | 夕 |
| bedtime | 就寝前 |

1つのお薬に複数のタイミングを設定可能。

### 3.3 日次チェック（今日の服薬）

- 今日の日付に基づき、飲むべきお薬をタイミング別に一覧表示
- 各お薬にチェック（服用済み）を付けられる
- チェックの取り消しも可能
- 全タイミングの服用状況をひと目で確認できるサマリー表示

### 3.4 カレンダー履歴

- 月単位のカレンダー表示
- 各日付に服薬状況のインジケーター（全服用 / 一部服用 / 未服用）
- 日付タップで当日の詳細（どの薬を飲んだか）を確認
- 月の前後移動

## 4. 非機能要件

### 4.1 技術スタック

| レイヤー | 技術 |
|---------|------|
| フレームワーク | Next.js (React) |
| 言語 | TypeScript |
| スタイリング | Tailwind CSS |
| データ保存 | localStorage |
| デプロイ | 静的エクスポート（`next export`） |

### 4.2 データ保存

- **localStorage** を使用し、サーバー不要で動作
- データはブラウザに保存（端末ごと）
- JSON 形式で保存

### 4.3 レスポンシブ対応

- **スマホメイン** のUI設計（モバイルファースト）
- タブレット・PCでも利用可能
- タッチ操作に最適化（ボタンサイズ 44px 以上）

### 4.4 パフォーマンス

- 初回表示 3秒以内
- 操作レスポンス 100ms 以内

## 6. データモデル

### 6.1 Medicine（お薬）

```typescript
type TimingSlot = 'morning' | 'noon' | 'evening' | 'bedtime';

interface Medicine {
  id: string;          // UUID
  name: string;        // お薬名
  timings: TimingSlot[]; // 服用タイミング（複数選択可）
  memo: string;        // メモ（任意）
  createdAt: string;   // 登録日時（ISO 8601）
}
```

### 6.2 DailyRecord（日次服薬記録）

```typescript
interface DailyRecord {
  date: string;        // 日付（YYYY-MM-DD）
  checks: Check[];     // 服薬チェックの配列
}

interface Check {
  medicineId: string;  // お薬ID
  timing: TimingSlot;  // タイミング
  taken: boolean;      // 服用済みかどうか
  checkedAt?: string;  // チェック日時（ISO 8601）
}
```

### 6.3 localStorage キー

| キー | 値 |
|------|------|
| `medicines` | `Medicine[]` |
| `records` | `DailyRecord[]` |
