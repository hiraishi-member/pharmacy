# UIデザイン方針

## コンセプト

**かわいい・清潔感・使いやすい**
女性向けの薬管理アプリ。白とピンクをベースに、やさしく温かみのあるデザイン。

## タイポグラフィ

- **フォント**: `Noto Sans JP`（日本語対応・読みやすい丸みのある字体）
- **見出し**: 600 weight
- **本文**: 400 weight
- **ベースサイズ**: 16px（スマホ最適化）

---

## コンポーネントライブラリ

**shadcn/ui** を採用。

理由:
- Next.js + Tailwind CSS と完全互換
- コンポーネントのソースコードを直接プロジェクトに配置するため自由にカスタマイズ可能
- ピンクテーマへの変更が CSS 変数1か所で完結

### Tailwind CSS テーマ設定（tailwind.config.ts）

```ts
colors: {
  primary: {
    DEFAULT: '#F472B6',
    dark: '#EC4899',
    light: '#FBCFE8',
  },
  background: '#FFF5F7',
  accent: '#DDD6FE',
}
```

### shadcn/ui CSS 変数（globals.css）

```css
:root {
  --primary: 322 81% 70%;         /* #F472B6 */
  --primary-foreground: 0 0% 100%;
  --background: 340 100% 98%;     /* #FFF5F7 */
  --border: 340 80% 90%;          /* #FECDD3 */
  --ring: 322 81% 70%;
}
```

## コンポーネント設計

### タイミングバッジ

```
朝   → 🌅 ピンク背景
昼   → ☀️ 黄色背景
夕   → 🌇 オレンジ背景
就寝前 → 🌙 ライラック背景
```

### 服薬チェックボタン

- 未チェック: 白背景・ピンクボーダー・`Pill` アイコン
- チェック済み: ピンク背景・白文字・`CheckCircle2` アイコン
- タップ時にふわっとアニメーション（`transition-all`）

### カード

- 角丸: `rounded-2xl`
- 影: `shadow-sm`
- ボーダー: `border border-pink-100`

---

## レイアウト原則

- **最大幅**: `max-w-md`（375px〜430px 想定）、中央寄せ
- **パディング**: 画面全体 `px-4`、カード内 `p-4`
- **ボトムナビゲーション**: 固定（`fixed bottom-0`）、高さ 64px
- **セーフエリア**: `pb-safe`（iOS対応）

---

## アニメーション

- チェック切り替え: `transition-all duration-200`
- ページ遷移: フェードイン（Next.js の`<motion>`なしでも可）
- ボタン押下: `active:scale-95`
